Comment fonctionne Internet et un site web ?

⏱️ Lecture ~9 min 🧩 Aucun prérequis ✅ Quiz en fin de chapitre

1 Accroche

Que se passe-t-il vraiment quand tu appuies sur Entrée ?

Tu tapes une adresse dans ton navigateur, genre monsite.fr, tu appuies sur Entrée, et 2 secondes plus tard, une page s'affiche devant toi. Tu t'es déjà demandé ce qu'il se passe réellement entre ces deux moments ?

Spoiler : il se passe beaucoup de choses, très vite — et comprendre ce mécanisme est la toute première brique pour comprendre le SEO. On démarre ici, à zéro, sans rien supposer que tu connaisses déjà.

2 Ce que tu vas apprendre

À la fin de ce chapitre, tu sauras

  • ✓ Ce qu'est concrètement Internet (pas la version « magique », la version réelle)
  • ✓ Ce qu'est un site web et de quoi il est fait
  • ✓ Ce qu'il se passe entre ton clic et l'affichage de la page
  • ✓ Pourquoi cette mécanique est la base de tout ce qu'on verra ensuite en SEO

3 Le concept expliqué simplement

Internet, c'est quoi en vrai ?

Oublie l'image du « nuage » flou qu'on voit dans les pubs. Internet, c'est un immense réseau d'ordinateurs connectés entre eux, partout dans le monde, qui peuvent s'échanger des informations.

💡 Analogie simple — imagine le réseau routier d'un pays. Les « villes » sont des ordinateurs (le tien, mais aussi des serveurs), les « routes » sont des câbles ou des ondes (wifi, 4G/5G), et ce qui y circule, ce sont des données : texte, images, vidéos.

Un site web, c'est quoi concrètement ?

Un site web n'est rien de plus qu'un ensemble de fichiers stockés sur un ordinateur qu'on appelle un serveur — une machine allumée 24h/24 dont le seul travail est d'attendre qu'on lui demande ses fichiers pour les envoyer.

Ces fichiers, ce sont principalement des fichiers HTML (le squelette), CSS (l'habillage visuel) et JavaScript (les interactions), plus des médias (images, vidéos).

💡 Si un site web était une maison : le HTML serait les murs et les pièces (la structure), le CSS la peinture et la déco (l'apparence), le JavaScript l'électricité et la plomberie (les interactions).

Que se passe-t-il quand tu tapes une adresse ?

Voici la séquence réelle, simplifiée, de ce qu'il se passe en une fraction de seconde :

  • 1 Tu tapes monsite.fr dans ton navigateur
  • 2 Le navigateur interroge le DNS, l'annuaire d'Internet, qui traduit ce nom en adresse IP
  • 3 Le navigateur « frappe à la porte » du serveur et demande les fichiers
  • 4 Le serveur répond et envoie les fichiers
  • 5 Le navigateur assemble ces fichiers sous tes yeux pour afficher la page

Tout ça en moins d'une seconde : c'est une requête (ta demande) et une réponse (ce que le serveur t'envoie).

4 Exemple concret

Ce que ton navigateur « voit » réellement

Fais un clic droit sur n'importe quelle page → « Afficher le code source de la page » (ou Ctrl+U). Tu y verras des éléments comme ceux-ci :

🌐 code-source.html
<h1>Bienvenue sur mon site</h1>
<p>Voici un paragraphe de texte.</p>
<img src="photo.jpg" alt="Une photo">

Ce n'est rien de plus que du texte structuré avec des « balises » qui disent au navigateur « ceci est un titre », « ceci est un paragraphe ». Tu n'as pas besoin de savoir l'écrire toi-même à ce stade.

5 Comment le mettre en pratique

Un petit parcours pour ancrer la mécanique

1

Observe le code source d'un site que tu connais bien

Clic droit → « Afficher le code source de la page ». Repère simplement des mots familiers comme <title>, <h1> ou <img>.

⚠️ Piège fréquent : tu vas tomber sur un mur de texte illisible. C'est normal, ne cherche pas à tout comprendre.
2

Identifie le nom de domaine

Dans https://www.exemple.fr/page, le nom de domaine c'est exemple.fr — l'équivalent d'une adresse postale pour ton site.

⚠️ Piège fréquent : confondre nom de domaine (l'adresse) et hébergement (le serveur qui stocke les fichiers) — deux choses différentes, souvent vendues séparément.
3

Comprends pourquoi un site peut être lent ou rapide

Plus il y a de fichiers à envoyer (et plus ils sont lourds, comme des images mal optimisées), plus ça prend de temps. On y reviendra en détail dans le palier consacré à la webperformance.

6 Le jargon de ce chapitre

Mini-lexique

TermeDéfinition simple
InternetLe réseau mondial qui relie des ordinateurs entre eux et leur permet d'échanger des données.
ServeurUn ordinateur allumé en permanence, qui stocke les fichiers d'un site web et les envoie quand on les demande.
HTMLLe langage qui structure le contenu d'une page (titres, paragraphes, images...).
CSSLe langage qui définit l'apparence visuelle d'une page.
JavaScriptLe langage qui rend une page interactive.
DNSLe système qui traduit un nom de domaine en adresse numérique.
Nom de domaineL'adresse d'un site web (ex : monsite.fr).
HébergementLe service qui fournit le serveur où sont stockés les fichiers d'un site.

7 Quiz — Vérifie que tu as compris

Question 1/2

Question 1 — Qu'est-ce qu'un serveur ?

A Un logiciel installé sur ton ordinateur personnel
B Un ordinateur allumé en permanence qui stocke et envoie les fichiers d'un site web
C Un autre nom pour désigner Google
D Le nom de domaine d'un site
💡 Bonne réponse : B. Un serveur est une machine dédiée, allumée 24h/24, dont le rôle est de répondre aux demandes des navigateurs en leur envoyant les fichiers du site.

Question 2 — À quoi sert le DNS ?

A À héberger les fichiers d'un site
B À rendre une page interactive
C À traduire un nom de domaine en adresse numérique compréhensible par les machines
D À afficher les couleurs d'une page
💡 Bonne réponse : C. Le DNS fonctionne comme un annuaire : il permet à ton navigateur de trouver l'adresse IP correspondant à un nom de domaine.
